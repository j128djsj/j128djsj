I am currently researching **full-duplex Speech Large Language Models (Speech LLMs)** for natural, real-time spoken interaction.

## 📚 Selected Research

### [Lightweight Speech Enhancement](https://doi.org/10.1016/j.dsp.2026.105987)

> **Lightweight speech enhancement with state-space model and depthwise separable convolution**

- **Venue:** *Digital Signal Processing*
- **Role:** First Author
- **Status:** Published (2026)
- **Highlights:** Lightweight SSM architecture, depthwise separable convolution, multi-scale context modeling, and perceptual compression

### [NoiseLoRA-SV](https://github.com/peter112231/NoiseLoRA-SV)

> **NoiseLoRA-SV: Hierarchical Noise-Conditioned Adaptation with Embedding Distillation for Robust Speaker Verification**

- **Venue:** *Interspeech 2026*
- **Role:** Co-first Author
- **Status:** Accepted (Oral Presentation)
- **Highlights:** Global noise-aware LoRA generation, local gating, noise reconstruction, and clean-teacher distillation
